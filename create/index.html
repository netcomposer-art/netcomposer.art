Take it further

A Composition is words, not a recording, so anyone can perform it, and each Performance comes out different. This page is just one Performer. Take your Composition away and perform it yourself with the open-source kit, hand it to an AI agent, or build your own Performer. Every take uses openly licensed sounds and keeps a record of where each sound came from, so the music can travel, branch and stay credited.

Open a file



Open a composition.md: one made here, or a published one (C major, Canon, blues, C minor, E♭ minor, A♭ major).


With the Performer kit 0.2.0 (Python, ffmpeg)


pip install git+https://github.com/netcomposer-art/nc-performer
nc perform composition.md --stub -o out/    # no LLM
nc render --plan plan.json -o out/          # your own plan
nc perform composition.md -o out/           # any OpenAI-compatible LLM


The kit is open source (MIT): github.com/netcomposer-art/nc-performer. It needs Python 3.10+ and ffmpeg. The default reverb hack is Dragonfly Hall: add pip install pedalboard and Dragonfly Reverb (apt install dragonfly-reverb, or its VST3). Without them the kit uses its synthetic hall, and the record says which reverb ran.


With an agent


Grok, ChatGPT, Claude, others: give it the composition.md and the skill, SKILL.md (plain text: SKILL.txt). It writes plan.json, renders, writes the record. More on Agents start here.
