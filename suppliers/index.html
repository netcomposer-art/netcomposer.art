NetComposer / Suppliers

Registered Suppliers are listed in suppliers.json, where agents look first, and will be checked (licenses and checksums) on every validation run. Today the registry is checked with the validator. Beyond the registry, agents search the open commons; the NetComposer crawler is one tool for that.

Register

  1. Publish a netcomposer.json index and per-sound manifests as described in the Supplier spec.
  2. Check it: python3 validate_supplier.py https://example.org/netcomposer.json (validate_supplier.py, Python standard library only).
  3. Open an issue on the site repository with the index URL, or a pull request adding an entry to suppliers.json.

This registration channel is proposed and may change. Statuses (proposed): active, pending, failing, withdrawn.
